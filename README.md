# Gestão de Projetos

Site publicado: <https://paineis-gerenciais.github.io/gestao-projetos/>

Este repositório tem **só o app pronto** (gerado a partir do repositório de
desenvolvimento, que é privado). Não edite `index.html` aqui — as mudanças
são feitas lá e publicadas com `publicar.py`.

| Arquivo | O que é |
|---|---|
| `index.html` | o app |
| `config.js` | configuração desta instalação (Firebase, nome, administrador inicial) |
| `vendor/` | SDK do Firebase |
| `assets/` | logotipo (`logo.png`, `logo-icone.png`), se houver |
| `firestore.rules` | regras de segurança desta instalação — publicar em Firebase › Firestore Database › Regras |
